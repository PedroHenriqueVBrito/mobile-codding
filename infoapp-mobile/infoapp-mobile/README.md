# InfoApp Mobile

## Descrição

O InfoApp Mobile é um aplicativo desenvolvido em React Native utilizando a plataforma Expo Snack. O projeto foi criado com o objetivo de demonstrar a implementação de uma aplicação mobile com múltiplas telas, navegação entre páginas, cadastro de perfil, configurações personalizáveis e área de contatos.

O sistema centraliza funcionalidades básicas encontradas em diversos aplicativos modernos, oferecendo uma interface simples, organizada e intuitiva.

---

## Objetivo

O projeto foi desenvolvido para demonstrar conceitos fundamentais do desenvolvimento mobile, incluindo:

* Navegação entre telas;
* Manipulação de componentes React Native;
* Gerenciamento de estado;
* Organização de interfaces gráficas;
* Desenvolvimento de aplicações multiplataforma.

## Funcionalidades

### Home

* Exibição de relógio digital em tempo real;
* Navegação para as demais telas do aplicativo;

* Cadastro de usuário;

## Pré-requisitos

Para executar o projeto são necessários:

* Computador, notebook, tablet ou smartphone com acesso à internet;
* Navegador atualizado;
* Plataforma Expo Snack;
* Expo Go (opcional para testes em dispositivos móveis).

Dependências utilizadas:

* @react-navigation/native
* @react-navigation/native-stack
* react-native-screens
* react-native-safe-area-context

---

## Instalação e Execução

### 1. Acessar o Expo Snack

Abra a plataforma Expo Snack no navegador.

### 2. Abrir o Projeto

Carregue os arquivos do projeto ou crie um novo Snack e copie os códigos.

### 3. Instalar Dependências

Adicione as dependências necessárias para navegação entre telas.

### 4. Executar

Execute o projeto através do botão Run ou aguarde a compilação automática.

### 5. Testar no Celular

Instale o aplicativo Expo Go e escaneie o QR Code gerado pelo Expo Snack.
